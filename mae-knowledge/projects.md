# Projects

## Solar Proposal System #project #featured #ai #systems #website
AI-Enabled Solar Proposal and Client Workflow System (Industrial Engineering x AI Automation x Client Workflow Design), live as the website Solar Solutions PH: https://solar-solutions-ph.vercel.app. The site opens with a 15-chapter scroll-driven 3D walkthrough of how a solar energy system works, then a seven-step Solar Assessment and Proposal app (Client Information, Energy Profile, Technical Site Inspection, System Configuration, Financial Analysis, System Recommendation, Generate Proposal) and "Sol", an AI solar assistant. Problem: manual repeated client information gathering, separate engineering calculation steps, slow proposal preparation, fragmented project data. Solution: structured client intake, validated engineering workflow, AI-assisted guidance (Gemini / Google AI Studio), automated proposal process and centralized data in Supabase, deployed on Vercel. Mae Ann's role: industrial engineering, process design, project coordination, automation and AI integration, system development. The code repository is private. Built during [[SUWECO Tablas Energy]]. Uses [[Business Systems]].

## Wedding Website #project #website #automation
Sam & Charis Wedding Website, built by Mae Ann for Ate Cha and Sam: https://sam-and-charis-wedding-web-app.vercel.app. Guests find their invitation by name, email or invite code and RSVP; each RSVP is sent by webhook to Google Sheets so the couple can see who accepted, the data is stored in Supabase, and guests get an automatic confirmation email. The site also has the event details, their story, gallery, attire guide, entourage, venue, gift guide and FAQs. It was used for their wedding on September 25, 2026 and worked successfully. Shows [[Client Workflow Automation]] applied outside engineering.
