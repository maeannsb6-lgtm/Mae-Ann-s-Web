# Projects

## Solar Proposal System #project #featured #ai #systems
AI-Enabled Solar Proposal and Client Workflow System (Industrial Engineering x AI Automation x Client Workflow Design). Problem: manual repeated client information gathering, separate engineering calculation steps, slow proposal preparation, fragmented project data. Solution: structured client intake, validated engineering workflow, AI-assisted guidance (Gemini / Google AI Studio), automated proposal process and centralized data in Supabase, deployed on Vercel. Mae Ann's role: industrial engineering, process design, project coordination, automation and AI integration, system development. Live app: https://stec-independent-app.vercel.app. Code: https://github.com/maeannsb6-lgtm/STEC-NEW. Built during [[SUWECO Tablas Energy]]. Uses [[Business Systems]].
